# Tafelhelden

Tafelhelden is gratis te gebruiken als installeerbare webapp. Open de beveiligde website op het apparaat waarop je de app wilt gebruiken en voeg hem toe aan je Dock of beginscherm:

**[Open Tafelhelden](https://thomaschavannes72-maker.github.io/tafelhelden-app/)**

## Installeren

- **Mac:** open de website in Safari en kies in de menubalk **Archief → Voeg toe aan Dock**. In Chrome kun je **Tafelhelden installeren** kiezen in het browsermenu.
- **iPhone:** open de website in Safari, tik op **Deel** en kies **Zet op beginscherm**.
- **iPad:** open de website in Safari, tik op **Deel** en kies **Zet op beginscherm**.

Daarna start Tafelhelden vanaf het eigen icoon en werkt het als een app. De webapp bewaart voortgang en profielen lokaal op het apparaat. De website kan na de eerste keer openen ook offline starten; online poulesynchronisatie is nog niet beschikbaar.

## Over native apps

Dit GitHub-project levert geen ondertekende macOS-app of installeerbaar iOS/iPadOS-bestand (`.ipa`). Apple vereist ondertekening voor installatie van native iPhone- en iPad-apps; distributie via de App Store vereist een Apple Developer Program-account. De gratis webapp hierboven kan zonder App Store-account aan het beginscherm of Dock worden toegevoegd.

De native iOS- en Android-projecten en bouwinstructies staan in [README-MOBILE.md](README-MOBILE.md).
